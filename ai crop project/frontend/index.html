            Project Documentation

            About PlantCare AI

            A hackathon-grade full-stack computer vision application bridging deep learning with practical agricultural stewardship.

            🎯

            Project Purpose & Mission

            Smallholder farmers and home growers lose an estimated 20–40% of their annual crop yields to preventable fungal and bacterial pathogens. Traditional diagnostic labs are often inaccessible or slow. PlantCare AI delivers instant, reliable foliar health assessments right in the browser, encouraging sustainable, non-chemical preventative interventions before diseases destroy crops.

            💻

            Technology Stack

            • Frontend: Semantic HTML5, CSS3 Grid/Flexbox, ES6+ Vanilla JavaScript. Zero heavy node dependencies for rapid loading.
            • Backend API: Python 3.11, Flask REST framework, Flask-CORS, python-dotenv.
            • Machine Learning: TensorFlow/Keras MobileNetV2 with ImageNet transfer learning weights and fine-tuning.
            • Image Processing: Pillow (PIL), NumPy array normalization, Lanczos resampling.
            • Data Storage: SQLite on-disk database with indexed schema for scan auditing.
            ⚠️

            AI Limitations & Ethical Disclaimers

            Deep learning models trained on laboratory leaf images (such as PlantVillage) can experience domain shift when deployed in natural field conditions with complex backgrounds, insect defoliation, or varied lighting. Softmax outputs represent relative class likelihoods, not calibrated probabilistic certainties. This software is designed strictly as an educational and decision-support aid.

            🏆

            Hackathon Presentation Highlights

            • Real Working Pipeline: Real weights, genuine SQLite persistence, and zero fake statistics.
            • Safe Fallbacks: Built-in low-confidence warnings (<60%) and out-of-distribution guards.
            • Eco-Friendly Agronomy: Prioritizes cultural sanitation, pruning, and organic bio-controls.
